# Splunk SOC Homelab Architecture

## Overview

Built a Security Operations Center (SOC) homelab using Hyper-V, Ubuntu Server, Splunk Enterprise, Sysmon, and Windows 11.

## Infrastructure

### Hyper-V Host

- Windows 11 Gaming Desktop
- Hyper-V Virtualization

### Splunk Server

- Ubuntu Server
- Splunk Enterprise

### Windows Endpoint

- Windows 11
- Sysmon
- Splunk Universal Forwarder

## Security Monitoring Goals

- Centralized logging
- Threat hunting
- Alert triage
- Incident response
- Endpoint monitoring

## Skills Demonstrated

- SIEM Administration
- Windows Event Analysis
- Sysmon Configuration
- Hyper-V Administration
- Log Analysis
